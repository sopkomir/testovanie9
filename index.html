Obvody a obsahy rovinných útvarov

Štvorec

o = 4 · a

S = a²

Obdĺžnik

o = 2 · (a + b)

S = a · b

Kosoštvorec

o = 4 · a

S = a · vₐ

Kosodĺžnik (rovnobežník)

o = 2 · (a + b)

S = a · vₐ = b · v_b

Trojuholník

o = a + b + c

S = a · vₐ : 2 = b · v_b : 2 = c · v_c : 2

Lichobežník

o = a + b + c + d

S = (a + c) · v : 2

Kruh a kružnica

o = 2 · π · r = π · d

S = π · r²

π ≐ 3,14

Pravouhlý trojuholník

c² = a² + b²

S = a · b : 2

Uhly v trojuholníku

α + β + γ = 180°

Kocka

V = a³

S = 6 · a²

Kváder

V = a · b · c

S = 2 · (a · b + b · c + a · c)

Hranol

V = S_p · v

S = 2 · S_p + S_pl

S_p – obsah podstavy, S_pl – obsah plášťa

Valec

V = S_p · v = π · r² · v

S = 2 · S_p + S_pl = 2 · π · r² + 2 · π · r · v
